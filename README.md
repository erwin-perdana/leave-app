# Leave Management Application

Leave management system built with Angular for the frontend and JSON Server as the mock backend.

## 🚀 Getting Started

### Installation

1. **Clone the repository**
   ```bash
   git clone git@github.com:your-username/leave-app.git
   cd leave-app

2. **Install dependencies**
   ```bash
    npm install

4. **Running the Application**

  To run angular and json server, you can use
  ```bash
  npm run start:all
  ```
  Note: You can see admin credentials inside db.json in admin property
